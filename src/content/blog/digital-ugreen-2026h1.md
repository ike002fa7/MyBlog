## 一、品牌速览

绿联（UGREEN）从最早的线材配件商起步，如今已发展为覆盖充电、存储、扩展、音视频四大品类的综合 3C 品牌。2026 上半年，绿联在 NAS 私有云和 Thunderbolt 5 扩展坞两大高端品类上集中发力，同时在 GaN 充电器和线材配件上持续更新。本文从 **NASync NAS、GaN 充电器、扩展坞/Type-C Hub、线材配件**四大品类切入，逐一剖析值得关注的热门产品。

## 二、绿联 NASync 私有云系列

这是绿联 2026 上半年最核心的产品线，也是其从「配件厂」向「科技品牌」转型的关键。

### 2.1 NASync DXP4800 Plus —— 四盘位甜点级

| 规格项 | 参数 |
|--------|------|
| CPU | Intel N100（4 核 4 线程，最高 3.4GHz） |
| 内存 | 8GB DDR5（可扩展至 32GB） |
| 盘位 | 4×3.5"/2.5" SATA + 2×M.2 NVMe (PCIe 3.0×2) |
| 网络 | 双 2.5GbE |
| 接口 | USB-C 10Gbps ×1, USB-A 3.2 ×2, HDMI 2.0 |
| 系统 | UGOS Pro |
| 价格 | 约 ¥2,199（空机） |

**实测体验**：

DXP4800 Plus 是绿联 NASync 系列中性价比最高的型号。N100 处理器在日常 NAS 场景（文件存储、照片备份、Docker 轻量应用、Plex 硬解转码）中完全够用。双 2.5GbE 网口支持链路聚合，配合 NVMe 缓存盘，大文件读写稳定在 280MB/s 以上。

UGOS Pro 系统相比初代 UGOS 进步明显。2026 版支持 Docker Compose、虚拟机管理器、AI 相册人脸识别，整体体验已接近 Synology DSM 的 80%。手机端 App 的自动备份照片功能稳定，支持 Live Photo。

**与竞品对比**：

| 维度 | 绿联 DXP4800 Plus | Synology DS923+ | QNAP TS-464 |
|------|-------------------|-----------------|-------------|
| CPU | N100（4 核） | Ryzen R1600（2 核） | N5095（4 核） |
| 内存 | 8GB DDR5 | 4GB DDR4 ECC | 8GB DDR4 |
| M.2 槽 | 2 个 | 2 个（仅缓存） | 2 个 |
| 2.5GbE | 双口 | 可选扩展 | 双口 |
| 价格 | ¥2,199 | ¥3,200 | ¥2,800 |

**优点**：
- 硬件配置遥遥领先同级竞品
- 双 2.5GbE + 双 M.2 扩展性强
- UGOS Pro 进步明显，Docker 支持完善
- 价格极具竞争力

**缺点**：
- 系统生态不如 Synology 成熟（插件/套件少）
- N100 不支持 ECC 内存
- 部分高级功能（监控中心等）仍待完善

**购买建议**：如果你追求硬件性价比并且愿意接受一个仍在快速迭代的系统，DXP4800 Plus 是目前四盘位 NAS 的最优选。群晖用户如果对 DSM 套件生态有深度依赖，建议观望 UGOS Pro 再迭代 1-2 个大版本后入手。

## 三、绿联 GaN 充电器

### 3.1 UGREEN Nexode 140W 3-Port GaN Charger

| 规格项 | 参数 |
|--------|------|
| 总功率 | 140W |
| 接口 | 2×USB-C + 1×USB-A |
| 单口最大 | C1 140W PD 3.1 |
| 技术 | GaN |
| 折叠插脚 | ✅ |
| 重量 | 约 220g |
| 价格 | 约 ¥349 |

**实测体验**：

三口分配策略：
- 单 C1：140W
- C1 + C2：100W + 40W
- C1 + A：100W + 22.5W
- 三口全插：65W + 45W + 22.5W

满载 140W 持续 30 分钟，外壳最高温度 52°C，控制得不错。给 MacBook Pro 16" 充电实测功率稳定在 130-140W。

**优点**：
- 140W 总功率覆盖笔记本需求
- 体积比 Apple 140W 原装小约 40%
- 3 口实用组合

**缺点**：
- C2 口单独使用仅 40W，不能双口都 100W
- 重量偏大（220g），比 Anker 同类重约 20g

**购买建议**：需要给笔记本+手机同时快充的用户，¥349 定价非常合理。如果只需要充手机，65W 旅行版更合适。

## 四、绿联扩展坞 / Type-C Hub

### 4.1 UGREEN Revodok Max 13-in-1 Thunderbolt 4 Dock

| 规格项 | 参数 |
|--------|------|
| 上行 | 1×Thunderbolt 4（98W PD） |
| 视频 | 双 HDMI 2.1 + DP 1.4，支持三屏 4K@60Hz |
| 数据 | 2×TB4 下行, 2×USB-A 10Gbps, 1×USB-C 10Gbps |
| 网络 | 2.5GbE |
| 读卡器 | SD 4.0 / microSD |
| 音频 | 3.5mm 复合接口 |
| 价格 | 约 ¥1,299 |

**实测体验**：

三屏输出是最大亮点。实测 MacBook Pro 通过一根 TB4 线连接后，可同时驱动 2 台 4K@60Hz + 1 台 4K@30Hz 显示器。Windows 笔记本通过 DP 菊花链可达三屏 4K@60Hz。

2.5GbE 网口实测上下行均接近 2.35Gbps（受限于 NAS 端），比传统千兆快 2 倍以上。所有端口同时使用时，外壳温度约 42°C，发热控制优秀。

**优点**：
- 三屏 4K 输出，视频生产力拉满
- 接口丰富，一插全通
- 2.5GbE 网口诚意足
- 做工优秀，铝合金机身

**缺点**：
- 价格不算便宜（但比 CalDigit TS4 便宜 ¥1,000+）
- 电源适配器偏大（180W 砖头）
- Mac 下三屏需 DisplayLink 驱动

**购买建议**：MacBook Pro / Windows 轻薄本用户的桌面扩展首选。对于非 TB4 设备（如 iPad Pro），会降级为 USB-C 模式，带宽受限。
